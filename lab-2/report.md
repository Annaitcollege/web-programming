# Звіт до лабораторної роботи №2

## Тема: Верстка сайту компанії згідно з інструкцією (HTML/CSS)


## Практично застосувати CSS для оформлення семантичної HTML-структури веб сторінки: підключення зовнішнього CSS, селектори, каскад, specificity, типи блоків і Box Model.


## _Виконання роботи_
- Створено односторінковий статичний web-сайт та публікація за допомогою GitHub Pages.
- Викориистано такі технології: HTML, CSS, Vscode, GitHub, GitHub Pages. Для самої верстки використано селектори елементів, класи,id.
- Реалізовано підключення CSS-файл через <link>.
