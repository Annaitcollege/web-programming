# Звіт до лабораторної роботи №1

## Тема: Імплементація блогу «Мої 3 найкращі міста світу». Розміщення проєкту в репозиторії GitHub

## Метою лабораторної роботи є набуття практичних навичок проєктування та реалізації багатосторінкового статичного web-сайту, його версіювання та публікації в мережі Інтернет.

## _Виконання роботи_
- Створено багасторінковий статичний web-сайт та публікація за допомогою GitHub Pages.
- Викориистано такі технології: HTML, CSS, Vscode, GitHub, GitHub Pages.
- Реалізовано меню навігації, форму зворотнього звʼязку.
