# Звіт до лабораторної роботи №3

## Тема: Адаптивна верстка веб сторінки за допомогою Flexbox,CSS Grid та препроцесора SCSS


## Набути практичних навичок перетворення вже створеної HTML/CSS-сторінки на адаптивний інтерфейс із використанням SCSS, Media Queries, Flexbox та CSS Grid. Студент має не створити новий сайт, а послідовно вдосконалити знайомий проєкт «Акустична варта»,застосувавши принципи responsive design.



## _Виконання роботи_
- Створено односторінковий статичний web-сайт та публікація за допомогою GitHub Pages.
- Викориистано такі технології: SCSS, Media Queries, Flexbox та CSS Grid.
- Реалізовано підключення SCSS-файл через  розширення Live Sass Compiler;
