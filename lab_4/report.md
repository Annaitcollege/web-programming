# Звіт до лабораторної роботи №4

## Тема: Робота з циклами, функціями та функціональними виразами в JavaScript.Консоль браузера.


## Реалізувати та пояснити алгоритм аналізу послідовності вимірювань: від перевірки даних і циклів до декомпозиції на функції та синхронної передачі функції як аргументу.


## Виконання роботи
* **Структура проєкту та завантаження скрипту:** Реалізовано підключення js-файл через <script src="/lab_4/js/monitoring.js" defer></script>.
* **Ініціалізація даних і констант:** оголосіть масив вимірювань `noiseLevels` (28 елементів), порогові значення `warningLevel = 70`, `criticalLevel = 85` та межі коректності `[30, 130]`.
* **Перевірка DevTools Console:** виведіть тестові повідомлення через `console.warn()` та `console.error()` для перевірки роботи фільтрів у консолі розробника.
* **Валідація вимірювань:** реалізуйте функцію `isValidLevel()` (*Function Declaration*) для відфільтрування фізично недостовірних даних.
* **Застосування Arrow Functions:** створіть стрілкові функції `isAboveThreshold` (з кількома параметрами) та `formatDb` (з одним параметром).
* **Пошук першого критичного вимірювання:** використайте цикл `for` з оператором `break` у функції `findFirstCritical()` для зупинки після першого значення $> 85\text{ dB}$.
* **Пошук моменту відновлення:** за допомогою циклу `while` у функції `findRecovery()` знайдіть серію з 3 послідовних коректних вимірювань $\le 70\text{ dB}$.
* **Пошук першого коректного значення:** використайте цикл `do...while` у функції `findFirstValid()`, обґрунтувавши виконання принаймні однієї перевірки до обчислення умови.
* **Обробка та фільтрація масиву:** проітеруйте масив циклом `for...of` із застосуванням оператора `continue` для пропуску некоректних даних та підрахунку статистики.
* **Дослідження Hoisting:** перевірте можливість виклику *Function Declaration* до її оголошення та виникнення `ReferenceError` при завчасному виклику *Function Expression* у `const`.
* **Вивід консольного звіту:** виведіть підсумкові дані за допомогою `console.group()` / `console.groupEnd()`, замініть крапку на кому в дробових числах та заповніть текстові блоки відповідно до вимог.
* **Публікація проєкту:** зафіксуйте зміни через Git, завантажте їх у репозиторій GitHub та розгорніть статичний сайт на GitHub Pages.
